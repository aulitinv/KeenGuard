# Чек-лист интерактивности интерфейса (Interaction Definition of Done)

Каждый визуальный компонент, интерактивная карта, график или диалоговое окно в KeenGuard обязаны строго следовать настоящему чек-листу перед сдачей в эксплуатацию.

---

### 1. Надежный клик и зона захвата (Click & Hit Target)
- [ ] **Достаточная площадь нажатия (Hit Target)**: для мелких графических элементов (SVG-круги, узлы графа, иконки) обязательно наличие прозрачной зоны захвата (`<circle fill="transparent" r="${r + 14}">` или padding не менее 8–12px). Минимальный размер интерактивной зоны — не менее 36×36 px.
- [ ] **Отсутствие блокировки текста (`pointer-events: none`)**: текстовые подписи и бейджи внутри кликабельных групп не должны содержать `pointer-events: none`, если они визуально составляют единое целое с элементом. Клик по названию хоста обязан приводить к тому же действию, что и клик по его иконке.
- [ ] **Явный курсор**: элемент обязан иметь `cursor: pointer` и отключение случайного выделения текста (`user-select: none`).

---

### 2. Строгое разделение Drag & Click (Порог смещения)
- [ ] **Кандидат на перетаскивание (`dragCandidate`)**: при нажатии мыши (`mousedown` / `touchstart`) запрещено сразу начинать перемещение, запускать физику или менять состояние. Фиксируются только начальные координаты `startX, startY`.
- [ ] **Порог перемещения (Drag Threshold)**: перетаскивание активируется в `mousemove` / `touchmove` **только** при реальном евклидовом смещении курсора более 5 пикселей:
  ```javascript
  const dist = Math.hypot(e.clientX - dragCandidate.startX, e.clientY - dragCandidate.startY);
  if (dist > 5) { /* активировать drag */ }
  ```
- [ ] **Чистый клик при отпускании**: если кнопка мыши отпущена (`mouseup`), а порог в 5 px не был превышен — выполняется стандартное действие клика.
- [ ] **Защита от двойного срабатывания (Debounce)**: обработчик клика должен игнорировать повторные вызовы в течение 300–400 мс.

---

### 3. Абсолютный запрет на `.innerHTML` в циклах анимации (DOM Stability)
- [ ] **Мутация атрибутов вместо пересоздания**: внутри `requestAnimationFrame`, `step()`, `mousemove` или быстрых таймеров категорически запрещено затирать контейнеры через `element.innerHTML = ...`.
- [ ] **Двухфазный рендеринг графов**:
  1. `buildDomElements()`: создает структуру DOM-элементов один раз (при смене фильтра или получении новых данных).
  2. `updatePositions()`: обновляет только координаты через `setAttribute('transform', ...)` и `setAttribute('x1', ...)`.
- [ ] **Сохранение фокуса и событий**: элементы DOM никогда не должны исчезать из дерева документа в момент удержания клавиши мыши, иначе браузер прерывает нативные цепочки событий.

---

### 4. Универсальное закрытие диалогов (Modal Dismissal)
- [ ] **Регистрация в реестре**: любое новое модальное окно или выезжающая шторка (`-modal`, `-drawer`) обязаны быть добавлены в массив `modalIds` функции `initModalDismissHandlers()`.
- [ ] **Закрытие по клавише Escape**: нажатие `Escape` обязано закрывать самое верхнее активное модальное окно.
- [ ] **Закрытие кликом мимо окна (Backdrop Click)**: клик по полупрозрачной подложке (вне карточки контента) обязан закрывать окно через `closeAnyModal()`.
- [ ] **Скрытие тултипов**: при открытии модального окна любые плавающие подсказки (tooltips) обязаны немедленно скрываться (`classList.add('hidden')`).

---

### 5. Сенсорные экраны и мобильные устройства (Touch & Mobile)
- [ ] **Touch-события**: интерактивные холсты (SVG/Canvas) обязаны содержать парные обработчики: `touchstart`, `touchmove`, `touchend`.
- [ ] **Адаптивность жестов**: панорамирование и зум холста не должны конфликтовать с прокруткой страницы.
- [ ] **Скрытие бокового меню**: при переходе по вкладкам на экранах шириной < 1024px боковое меню обязано автоматически сворачиваться.
