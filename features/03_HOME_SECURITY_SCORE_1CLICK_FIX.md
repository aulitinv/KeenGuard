# План реализации: Индекс безопасности сети с решением в 1 клик (Home Security Score & 1-Click Fix)

## 1. Цель и назначение
Дать пользователю четкий, наглядный и измеримый индикатор защищенности домашней сети (0–100%) без необходимости разбираться в логах фаервола. При наличии проблем система предлагает интерактивные карточки с кнопкой мгновенного устранения («Исправить в 1 клик») либо пошаговой инструкцией.

## 3. Алгоритм расчета индекса безопасности (0–100%)

Базовое значение: **100 баллов**. При обнаружении рисков вычитаются штрафные баллы:

| Фактор риска | Штраф | Обоснование |
|---|---|---|
| **Опасный проброс портов UPnP** | -25 баллов | Порты 554 (RTSP), 80/8080 (HTTP), 23 (Telnet), открытые камерами или IoT наружу |
| **Неопознанные активные устройства** | -10 баллов (макс. -30) | Устройства без назначенного профиля и категории |
| **IoT-устройство с аномальным трафиком** | -15 баллов | Непрерывный исходящий трафик >1.5 Мбит/с с датчика/камеры |
| **Smart TV без блокировки рекламы/трекеров** | -10 баллов | Телевизор в сети без активного DNS Sinkhole пресета |
| **Слабая аутентификация Wi-Fi** | -20 баллов | Сеть с WEP/WPA1 или открытая гостевая сеть без шифрования |
| **Отсутствие Npcap/драйвера захвата** | -10 баллов | L2-анализ аномалий (ARP-спуфинг) работает в ограниченном режиме |
| **Активная ротация случайных MAC (LAA)** | -5 баллов | Смартфон скрывает аппаратный адрес, усложняя аудит |

### Градация оценки
- **90 – 100 баллов (Зеленый)**: 🟢 «Отлично. Сеть под надежной защитой».
- **70 – 89 баллов (Желтый)**: 🟡 «Хорошо, но есть уязвимости».
- **50 – 69 баллов (Оранжевый)**: 🟠 «Требуется внимание — обнаружены риски».
- **0 – 49 баллов (Красный)**: 🔴 «Критическое состояние — сеть уязвима».

## 4. Механизм «1-Click Fix» и интеграция с роутером

Каждая рекомендация имеет уникальный `action_id`, выполняемый через бэкенд:

### 1. `close_dangerous_upnp`
- **Что делает**: отправляет команду в роутер (Keenetic RCI / OpenWrt miniupnpd) для немедленного удаления сопоставления портов.
- **Подтверждение**: отображает диалог подтверждения с указанием затронутого порта и IP.

### 2. `enable_tv_sinkhole`
- **Что делает**: включает DNS-фильтрацию рекламных доменов и серверов сбора телеметрии для профиля Smart TV.
- **Эффект**: блокировка рекламы в приложениях и предотвращение отправки скриншотов ACR на сервера вендора.

### 3. `quarantine_untrusted_device`
- **Что делает**: применяет профиль нулевого интернета (`No Internet` / WAN Drop) для указанного устройства.

### 4. `guide_guest_wifi_isolation`
- **Что делает**: открывает пошаговое руководство с иллюстрациями, объясняющее, как переключить опасное устройство в физически изолированную Гостевую Wi-Fi сеть роутера.

## 5. Технический реализм (AGENTS.md Compliance)

> [!IMPORTANT]
> **Принцип честности перед пользователем:**
> Если действие требует физического вмешательства (например, перемещение умной колонки в гостевую сеть для истинной L2-изоляции), система прямо заявляет:
> *«Программное отключение интернета защищает от внешних хакеров, но устройство все еще видит ваш компьютер в домашней сети. Для полной изоляции переключите его на гостевой Wi-Fi»*.
> Никаких фиктивных галочек «Устройство изолировано», если трафик L2 внутри моста не заблокирован аппаратно.

## 6. Новые API-эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/security/score` | Возвращает текущий балл, детальный список списаний и активные карточки действий |
| `POST` | `/api/security/fix` | Выполнение действия исправления (`{"action_id": "...", "target": "..."}`) |
| `POST` | `/api/security/ignore-recommendation` | Временное скрытие рекомендации пользователем |

## 7. План тестирования
1. **Тест формулы расчета**: Юнит-тесты на проверку правильности вычитания баллов и формирования итоговой категории.
2. **Тест выполнения 1-Click Fix**: Мокирование команд роутера при удалении UPnP-правила и активации DNS-фильтров.
3. **Тест персистентности игнорируемых рекомендаций**: Проверка сохранения скрытых карточек в SQLite.
